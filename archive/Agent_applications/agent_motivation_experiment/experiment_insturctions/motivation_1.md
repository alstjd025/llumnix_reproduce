실험 목적
LLM request 에는 3가지 type 이 있다고 가정.
1. Latency sensitive (TTFT, TBT)
2. Throughput sensitive (best effort, latency 제약 크지 않음)
3. End to End latency sensitive (request completion latency)
3. Agentic (multiple requests are compund, latency sensitive, throughput sensitive, and end to end latency sensitive)

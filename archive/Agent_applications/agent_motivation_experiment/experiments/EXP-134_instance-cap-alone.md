# EXP-134 — 배포 설정에서 클래스별 인스턴스 상한 하나만 뺀다

실행 전에 씀, 결과를 아래에 채웠다. 2026-09-14 KST.

## 1. 왜

EXP-133 의 누적 계단이 상한 제거를 **+5.6~+9.7 점**(좋아짐)으로 읽는데, 그것은
**클래스 선호와 보유가 이미 꺼진 상태**의 값이다. EXP-107 은 선호가 **켜진** 상태에서
상한을 채택했으므로, **배포 설정을 바꿀지 정하는 값은 상한 하나만 뺀 것**이고 그 셀이
없었다. 보유의 단독 값은 EXP-131 이 이미 쟀다(`fsv3t75nopend` 74.1/75.6 대 대조군
73.6/75.5, 즉 0).

## 2. 설정

배포 설정(`fsv3capgnofrct75`)에서 `--fluidserve-class-instance-cap=false` 하나만 바꾼
`nocapt75`. **arm 정의를 대조군과 diff 해서 다른 항목이 `FS_INSTANCE_CAP` 하나뿐인 것을
확인했고**, 기동 줄도 두 반복 모두 `instancecap=false, affinity=true, pend=true,
flux=true, horizon=100, capmult=3.0` 으로 확인했다(`verified` 2 회).
`FS_CAP_WINDOW_MULT=3.0` 은 상한이 꺼지면 작동하지 않지만, arm 이 대조군과 **기동 줄에
나타나는 플래그 기준으로도** 하나만 다르도록 명시로 고정했다.

정적 2100 rpm(35 req/s), 8 분, t75, **2 반복**. 채점 `FS_SWE_TBT_MS=75`.

## 3. 판정 규칙 (실행 전)

\|Δ\| < 1.0 차이 없음 / 1.0~3.0 판정 안 함 / ≥ 3.0 실재.

**예측**: 누적에서 +5.6~+9.7 이었으므로 **비슷하거나 조금 작을 것**으로 봤다(선호가 켜져
있으면 상한이 덜 구속할 수 있다고 생각했다).

## 4. 결과 — 예측보다 크다. **+10.3 ~ +12.5 점**

| | 대조군 r1 / r2 | **nocapt75 r1 / r2** | 차이 |
|---|---|---|---|
| 모든 도착 | 75.3 / 73.3 | **85.8 / 85.6** | **+10.3 ~ +12.5** |
| admitted | 99.2 / 98.5 | 99.1 / 99.2 | 0 |
| 거절률 | 22.0% / 23.4% | **11.9% / 12.1%** | **−10.1 ~ −11.5** |
| goodput (출력 토큰/s) | 13,259 / 12,990 | **14,668 / 14,633** | **+10.4 ~ +12.9%** |

**처리군 두 반복이 0.2 점 안에 있다**(85.8 / 85.6). 대조군의 반복 폭 2.0 점보다도 작다.

**누적값(+5.6~+9.7)보다 크다.** 누적 쪽은 클래스 선호가 이미 꺼져 있었고 선호가 2~4 점을
벌므로, 그만큼 낮게 읽힌 것이다. **즉 상한과 선호는 서로 상쇄하지 않는다 — 선호를 켠 채
상한만 빼는 것이 가장 좋다.**

### 무엇이 좋아졌나

**거절률이 절반이 되고 admitted 달성률은 그대로다**(99.1~99.2 대 98.5~99.2). 즉 상한이
막고 있던 요청들은 **받아들였으면 SLO 를 지켰을 요청들**이다. goodput 이 같은 비율로 오르는
것이 그 확인이다.

## 5. ⚠ 이것이 **설정하지 않는 것**

**EXP-107 은 상한을 정적 셀에서 채택하지 않았다.** 채택 근거는 **한 시간 mix-shift trace 의
재분배**였다 — chat 이 많은 구간에서 deepresearch 가 8~12 점 올랐다. **정적 한 셀은 그 양을
재지 않는다.**

→ **EXP-135 를 걸었다**(2026-09-14 06:24 KST): 같은 변경을 **한 시간 trace 에서** 2 반복.
대조군은 EXP-109 의 2 반복(78.5 / 77.8). **총점만 보지 말고 클래스별·구간별로 볼 것** —
총점이 올라도 chat 이 많은 구간에서 deepresearch 가 그 8~12 점을 잃으면, 상한은 **격리를
대가를 치르고 사는 것**이고 그것은 결함이 아니라 설계 선택이다.

## 6. 이 실험이 만든 규칙

**누적 ablation 의 단계 값을 그 요소의 단독 값으로 쓰면 안 된다.** 누적은 *"위의 것들이
이미 없는 세계에서"* 의 값이고, 채택 결정은 *"지금 배포 설정에서"* 의 값으로 내린다.
EXP-133 의 계단은 **중복 구조를 보는 도구**이지 채택 값을 주는 도구가 아니다.
이번에는 두 값이 4.9 점 달랐고 **단독 쪽이 더 컸다.**

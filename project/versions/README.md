# FluidServe 버전 목록

2026-11-10부터 구성을 "논문 버전", "대조군" 같은 말 대신 **버전으로 부른다**(사용자 결정). 번호 규칙은 v0.1.1 때 정한 것을 그대로 쓴다:

- **minor(0.x)**: 기본 구성에서 결정 규칙이 바뀌거나, 판정에 들어가는 양의 정의가 바뀐다.
- **patch(0.x.y)**: 정책이 읽는 입력이나 계측만 바뀌거나, 기본값이 꺼진 플래그만 더해져 기본 구성의 결정이 그대로다.
- **후보(-후보N)**: 실험 중이고 아직 채택하지 않은 구성.
- 플래그 하나만 켜 본 변형은 "버전 + 플래그"로 부른다(예: "v0.5 + pace horizon 50").
- 버전마다 명세 문서 하나: 바이너리 md5(파드 안 `md5sum /proc/1/exe`로 확인한 값), 플래그, 앞 버전과 다른 점, 그 버전으로 측정한 실험.
  태그는 문서에 적은 이름이다. git 태그는 push와 함께 사용자가 정한다.

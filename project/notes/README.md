# 메모

실험 대시보드(`dashboard/`)의 run 페이지와 실험 기록 페이지에서 사용자가 쓴 메모가 파일 하나씩으로 쌓이는 곳이다
(2026-10-20 사용자 요청).

- `runs/<run 디렉토리 이름>.md` — run 하나에 대한 메모
- `exp/<EXP 기록 파일 이름>.md` — 실험 기록(EXP-NN) 하나에 대한 메모

대시보드는 이 파일들을 고치기만 하고 지우지 않는다. git으로 이력을 남기려면 커밋한다.
수치의 정본은 여전히 `project/evidence.md`이고 판정 규칙은 각 EXP 기록에 있다 — 메모는 그 둘을 대신하지 않는다.
